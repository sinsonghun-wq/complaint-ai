# 로그인 첫 화면과 관리자 파일 메뉴 정리

- 일반 사용자는 로그인 직후 `AI 추천 답변`을 표시한다. 기존 새 민원 작성과 작성한 민원 메뉴는 유지한다.
- 관리자는 로그인 직후 `분류 목록 · 민원 접수`를 표시한다. 별도 `민원 접수` 사이드 메뉴를 제거하고, 분류 목록에서 민원을 선택하는 접수·답변 흐름은 유지한다. 접수 상세에서도 통합 메뉴의 선택 표시를 유지한다.
- 관리자의 `새 민원` 메뉴와 파일 화면 제목은 `파일 자료 관리`로 정리한다.
- 첫 업로드 영역은 `외부 민원 저장`으로 표시한다. 민원 파일을 요약·분류해 부서 목록에 저장한다는 설명과 `민원 파일 선택`, `외부 민원 저장 시작` 문구를 사용한다.
- 두 번째 영역의 `RAG용 데이터 삽입` 이름은 유지하고, 법률·규칙·사례를 AI 추천 답변의 근거 자료로 저장하는 용도를 설명한다.
- 기존 파일 형식, API, RAG 처리, 진행률, 취소 및 저장 방식은 변경하지 않는다.

## 검증

- 기존 화면 테스트의 메뉴·버튼 이름과 파일 화면 진입 경로를 수정했다. 새 테스트를 추가하지 않았다.
- `npm run test:admin`: 화면 84개와 진행률 4개 통과.
- `npm run build`: 성공.
- 실제 로컬 앱에서 기존 관리자·일반 사용자 계정으로 로그인해 서로 다른 첫 화면을 확인했다.
- 관리자 파일 화면에서 두 업로드 영역의 제목·설명·버튼과 사이드 메뉴를 확인했다. 검증 중 파일 업로드·민원 접수·삭제·AI 답변 생성을 실행하지 않았다.
- 전체 테스트의 이전 채팅 계약 관련 실패는 앞선 작업에서 확인한 별도 항목이며, 이번 검증은 현재 화면 계약을 대상으로 했다.
